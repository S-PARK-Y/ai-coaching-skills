# AI 复盘教练合集 (AI Coaching Skills)

这个文件夹包含了两个专门用于“复盘”的 AI Skill，它们适用于不同的场景和目标。

## 📁 包含的 Skills

### 1. 业务项目复盘教练 (`project-retrospective-coach`)
* **适用场景**：业务项目结项、需求上线复盘、评估数据复盘等。
* **核心特点**：
  * **犀利直接**：不写废话流水账，直接扒开“平均数”看底层的异常数据。
  * **灵魂拷问**：从“伪需求”、“竞品差距”、“平台护城河”等角度进行挑战。
  * **结构化输出**：最终输出带有红绿灯 🔴🟡🟢 数据指标、可视化对比图表的高质量飞书汇报文档。

### 2. 个人成长复盘教练 (`personal-case-study-coach`)
* **适用场景**：复盘一次工作冲突、失败经历、关键决策、协作问题，或提炼个人成长 Case Study。
* **核心特点**：
  * **提供安全感**：不评判对错，允许脆弱和尴尬，像 Mentor 一样引导。
  * **三层复盘**：从“事实层（发生了什么）”到“认知层（当时怎么想的）”再到“成长层（未来怎么做）”。
  * **可分享性**：最终输出一份脱敏的、结构清晰的 8 步案例文章，方便内网分享或个人复盘沉淀。

## 🚀 同事们如何使用

如果你使用的是 **Opencode** 等支持本地 Skill 的大模型客户端工具：

1. 打开你的终端 (Terminal)。
2. 将这两个文件夹复制到你的本地 skills 目录（通常是 `~/.agents/skills/`）：
   ```bash
   cp -r project-retrospective-coach ~/.agents/skills/
   cp -r personal-case-study-coach ~/.agents/skills/
   ```
3. 在工具中唤起对应的 Coach 即可开始使用：
   * 业务复盘：“帮我复盘一下上周上线的那个转化率不达预期的项目……” -> 会自动触发 `project-retrospective-coach`
   * 个人复盘：“我上周经历了一次跨部门协作冲突，心里挺委屈的，想复盘一下……” -> 会自动触发 `personal-case-study-coach`
